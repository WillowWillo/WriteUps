# 🔒 Real-World Vulnerability Research & Redacted Disclosures

Esta pasta é dedicada ao registro de análises, relatórios e estudos de caso de vulnerabilidades reais que encontrei em sistemas, aplicações e APIs em ambientes de produção.

## ⚖️ Divulgação Responsável (Responsible Disclosure)

Todos os conteúdos publicados nesta seção seguem rigorosamente preceitos éticos e de transparência:

1. **Sanitização de Dados:** Informações sensíveis — como nomes de empresas, endereços IP de produção, tokens de autenticação, chaves de API, domínios corporativos e Dados Pessoais (PII) — são estritamente anonimizadas ou censuradas.
2. **Mitigação Concluída:** Os achados aqui documentados foram devidamente reportados aos responsáveis ou devidamente corrigidos antes de qualquer publicação.
