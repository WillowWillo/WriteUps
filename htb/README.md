# 📦 Hack The Box — Walkthroughs & Methodologies

Esta seção contém a documentação das resoluções de máquinas e laboratórios do **Hack The Box (HTB)**. 

Diferente de resoluções focadas puramente na captura mecânica de flags, os registros aqui priorizam:
* **Entendimento da aplicação:** Mapeamento profundo do perímetro e análise do código/comportamento da aplicação.
* **Acesso Inicial (Initial Access):** Exploração detalhada de falhas lógicas, APIs e serviços expostos.
* **Documentação das rotas de escalação de privilégio:** Passo a passo técnico do ganho de acesso como usuário e administrador (`root`/`SYSTEM`).
